# トリッカフラワー 公式サイト

ブラウザゲーム「トリッカフラワー 〜花咲く忍の里〜」の公式サイト。

- ゲーム本体: https://torika-flower-sfc.vercel.app/ （リポジトリ: `EarthKey/Torika_Flower_SFC`）
- 設計図: ボルト `07_Anime_Studio/NinjaGames/Torika/公式ページ設計図_20260804.md`

## 構成

**ビルド不要の素のHTML/CSS**です。`index.html` と `style.css` の2枚だけで動きます。
Vercelでは Framework Preset = Other、ビルドコマンドなしで配信されます。

```
index.html          本体（全セクション・幕開けと四季のJSも内包）
style.css           全スタイル
assets/
  logo.png          タイトルロゴ（市松背景を除去した透過版）
  ogp.png           X共有用 1200x630
  favicon.svg
  season/           四季の里のゲーム画面スクリーンショット4枚
  face/             登場人物の顔グラ14枚（3:4の透過キャンバスへ下寄せで統一）
  howto/            遊び方の紹介イラスト3枚
```

## 画像の方針（重要）

**ギャラリーの解放報酬をサイトに載せない。** ゲーム内ギャラリーのイラスト（`illust_*` / `memory_*`）は
依頼を叶えた人だけが見られる報酬なので、サイトでは使わない。代わりに、

- 四季のセクション → 各里の**実際のゲーム画面**
- 登場人物 → 話しかければ誰でも見る**顔グラ**

を使う。実物のドット絵を正しく見せられる利点もある。

## 更新するときの注意

- ゲーム側のURLは `index.html` の iframe `src` と OGP の2箇所に直書き
- リンクを増やすときは `.links` の `li` を1つ足す（教材の枠を足す位置にコメントあり）
- 幕開けは**毎回表示・クリックでスキップ可**。動きを減らす設定の人には出さない
